# BnsPluginTables
Generated Blade & Soul NEO datafile structs for all data types from reverse-engineered client metadata, matching the game client structs at exact byte offsets for safe record casting.

## Disclaimer
The generated code in this project may not adhere to best practices and might sacrifice readability for the sake of functionality.  
All record types include their own enums to be self contained. Korean words in enums have been romanized from hangul to latin letters.
